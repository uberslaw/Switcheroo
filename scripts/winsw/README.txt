  https://github.com/winsw/winsw/releases/tag/v2.12.0
  SHA256 B5066B7BBDFBA1293E5D15CDA3CAAEA88FBEAB35BD5B38C41C913D492AADFC4F

This folder should contain:
  WinSW.NET461.exe   (downloaded by install-service.ps1, or placed here for offline install)
  Switcheroo.exe     (copy of the wrapper, created by install-service.ps1)
  Switcheroo.xml     (generated by install-service.ps1 with absolute paths)

Offline / no GitHub:
  1. Download WinSW.NET461.exe from the release URL above (requires .NET Framework 4.6.1+,
     present on current Windows 10/11 corporate images).
  2. Copy it into this folder as WinSW.NET461.exe
  3. Re-run scripts\install-service.ps1 as administrator.

Do not use Visual Studio. Do not use the 17 MB self-contained WinSW-x64.exe unless
.NET Framework 4.6.1 is missing (unusual).
